# Контент Genius

Папки и файлы разделены по назначению, чтобы библиотеку можно было расширять без правки интерфейса.

| Раздел | Источник | Как обновлять |
| --- | --- | --- |
| Учебник | `public/lecture-libraries/` | Добавить JSON и запись в `index.json` |
| Формулы | `app/formulas-data.js` | Добавить раздел или формулу в массив данных |
| Справочные материалы | `app/reference-materials.js` | Добавить карточку в набор справочных разделов |
| Задачник | `bank/` | Править исходный банк и выполнить `npm run bank:build` |
| ФИПИ | `app/oge-task-data-*.mjs` | Добавить проверенную задачу в файл нужного типа |
| Лабораторные работы | отдельная библиотека в следующей версии | Пока модуль показывает состояние «не загружена» |

`content/lecture-formulas.json` — воспроизводимый источник встроенных лекций. Скрипты преобразования находятся в `scripts/`, а пользовательские данные и прогресс хранятся отдельно от файлов библиотек.
