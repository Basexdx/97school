# Genius v5 — server + PWA + offline-first

Технический прототип образовательного приложения Genius.

## Что есть в v5

- Next.js 16 + React 19;
- Cloudflare Worker API + D1 schema;
- вход ученика по персональному коду;
- `PENDING -> APPROVED/REJECTED` с ручным подтверждением учителем;
- коды и сессионные токены хранятся на сервере только как хэши;
- PWA manifest + service worker;
- IndexedDB для офлайн-контента;
- отдельная вкладка **«Офлайн-материалы»**;
- загрузка отдельной темы или всего текущего класса;
- локальная очередь офлайн-событий;
- `POST /api/student/sync` для серверного подтверждения событий;
- защита от повторной отправки одного события;
- XP теста вычисляется сервером, а не доверяется клиенту;
- удаление офлайн-материалов не удаляет прогресс и XP.

## Первый локальный запуск

В папке проекта:

```bash
npm install
npm run setup:local
npm run dev
```

`setup:local` создаст `.dev.vars`, выведет локальный секрет учителя и применит `cloudflare/schema.sql` к локальной D1.

Открыть:

```text
http://127.0.0.1:3000
```

API Worker работает локально на:

```text
http://127.0.0.1:8787
```

Next.js проксирует запросы `/api/*` на Worker.

## Офлайн-режим

1. Открыть тему.
2. Нажать **«Скачать тему»** либо открыть **«Офлайн-материалы»** и скачать курс.
3. Материал сохраняется в IndexedDB этого устройства.
4. При отсутствии сети действия ученика помещаются в локальную очередь.
5. После появления сети Genius пытается отправить очередь в `/api/student/sync`.
6. Сервер проверяет события и только затем подтверждает XP/прогресс.

Подробно: `docs/OFFLINE_V1.md`.

## Важное ограничение текущего UI

Worker и D1 backend уже подготовлены, но часть экранов ученика/учителя всё ещё использует демонстрационное React-состояние из прототипа. Следующий этап — полностью переключить UI входа, approval flow, профиль и рейтинг на реальные API endpoints.

## Проверка перед публикацией

```bash
npm audit
npm run build
```

Цель — `0 vulnerabilities` и успешная production-сборка.

## Безопасность

Genius не требует от ученика email, телефона, ФИО, модели устройства, IMEI, контактов, геолокации или доступа к данным других приложений. Учебные события доступны только внутри Genius. Все production-запросы должны работать через HTTPS.

### Как открыть уроки

1. `npm install`
2. `npm run setup:local`
3. `npm run dev`
4. Открыть `http://127.0.0.1:3000`
5. Войти демонстрационным кодом `GNS-8K4P-X7M2`, подтвердить запрос в кабинете учителя.
6. Открыть **Обучение → 8 класс**.

Примечание: текущий загруженный PDF содержит 150 страниц и §1–§40. Поэтому v6 покрывает именно эти параграфы; при добавлении продолжения учебника карта курса расширяется без смены архитектуры.

## v8 — интерактивная переработка курса 8 класса

В этой версии все уроки, которые присутствуют в предоставленном PDF учебника, доведены до интерактивного формата: **§1–§40**. Для §13–§40 добавлены подробные шаги урока, тематические визуальные модели и расширенные итоговые тесты.

Исходный PDF, предоставленный для этой сборки, содержит 150 страниц и заканчивается **§40 «Электрическое сопротивление проводника. Закон Ома для участка цепи»**. Поэтому §41–§60 намеренно не выдумываются. Для их разработки нужна следующая часть/полная версия учебника, содержащая эти параграфы.
