# 97school

MVP веб-сервиса для школьников: решение задач, автоматическая проверка, XP, прогресс и рейтинг.

## Запуск

```bash
npm install
npm run dev
```

Откройте `http://localhost:3000`.

## Уже работает

- 5 демонстрационных задач по математике, физике и информатике
- проверка ответов
- подсказки
- начисление XP только за первое правильное решение
- сохранение прогресса в браузере
- рейтинг и профиль
- адаптивный интерфейс

## Следующий этап

Авторизация, PostgreSQL, серверная проверка, настоящая таблица лидеров и кабинет преподавателя.
