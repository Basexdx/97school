# Библиотеки учебника Genius

Эта папка содержит независимые библиотеки лекций. Для каждого класса используется отдельный JSON-файл, а `index.json` перечисляет файлы, которые приложение подключает при запуске.

## Как добавить свою библиотеку

1. Скопируйте `template.example.json` и переименуйте файл, например в `mechanics-extra-9.json`.
2. Задайте уникальный `id`, класс `grade` и заполните массив `lessons`.
3. Добавьте имя файла в `index.json`.
4. Формулы записывайте в синтаксисе KaTeX, например `v=\\frac{s}{t}`.
5. Выполните `npm run build:standalone` и проверьте темы на ПК и телефоне.

Код приложения, прогресс, XP и ответы находятся отдельно от библиотек. Поэтому замена JSON-файла не сбрасывает данные ученика. Полное описание полей есть в `docs/lecture-libraries.md`.
