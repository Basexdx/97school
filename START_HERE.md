# Genius v13 — 319 задач + запуск в один клик

## Самый простой запуск на Windows

Дважды щёлкните **`Genius_Start.vbs`**.

При первом запуске Genius сам:
1. проверит Node.js;
2. установит зависимости, если их ещё нет;
3. соберёт приложение, если сборка отсутствует;
4. запустит локальный веб-сервер скрыто;
5. откроет `http://127.0.0.1:3000` в браузере.

Чтобы создать красивый ярлык на рабочем столе, один раз запустите:

**`Create_Genius_Desktop_Shortcut.vbs`**

После этого Genius можно открывать обычным двойным кликом по ярлыку.

## Ручной запуск для разработки

```bat
npm ci
npm run dev:web
```

или production-режим:

```bat
npm run build
npm run start:web
```
