# Genius v14 — 7 и 8 классы

Ветка разработки: **`dev`**.

## Что добавлено в v14

- новый банк **7 класса** по сборнику А. В. Перышкина, диапазон задач №1–168;
- опубликованы 71 расчётная/объективная задача, качественные задачи исключены;
- графики и измерительные рисунки перерисовываются средствами интерфейса Genius без подписей с номерами рисунков;
- уровни сложности: базовый / повышенный / высокий;
- XP за правильный ответ зависит от номера попытки: 100% → 70% → 40% → 20% начиная с четвёртой попытки;
- 8 класс и его банк из 319 задач сохранены;
- на странице `/tasks` можно переключаться между 7 и 8 классом.

## Запуск текущей версии на Windows

При первом запуске откройте PowerShell в папке проекта:

```bat
npm ci
npm run setup:local
```

Введите почту учителя и сохраните сгенерированный пароль. Затем запускайте оба сервиса командой:

```bat
npm run dev
```

Откройте `http://127.0.0.1:3000`. Эта команда запускает веб-приложение и API, необходимый для входа. Для последующих запусков повторно выполнять `setup:local` не нужно.

## Однокнопочный запуск

После `setup:local` можно открыть `Genius_Start.vbs`. Он проверит и запустит веб-приложение вместе с API. Если конфигурация ещё не создана, лаунчер покажет команду для первого запуска.

## Режим разработки с локальным API

Если локальная база была удалена или повреждена, повторно примените схему:

```bat
npm run setup:local
npm run dev
```

Откройте `http://127.0.0.1:3000/tasks`.

`setup:local` сохраняет существующую локальную базу и повторно применяет безопасную схему банка задач; результаты и XP не удаляются.

## Быстрая проверка

```bat
npm run test:bank
```

Сборка автоматически восстанавливает сжатый исходный пакет 7 класса, проверяет его структуру и создаёт статические файлы банка.

После подтверждения входа ученика его сессия автоматически восстанавливается при следующем открытии приложения; персональный код повторно вводить не нужно.
