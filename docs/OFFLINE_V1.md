# Genius — offline-first v1

## Цель

Ученик может заранее скачать тему или курс, затем читать материал и решать задания без сети. После восстановления интернета накопленные учебные события отправляются на сервер. Рейтинг и окончательный XP подтверждает только сервер.

## Локальное хранилище

IndexedDB `genius-offline`, версия 1:

- `packages` — список скачанных тем/курсов, версия, размер, время загрузки;
- `content` — сам офлайн-контент;
- `syncQueue` — события, которые ещё не подтверждены сервером;
- `meta` — служебные локальные данные для будущих миграций.

Удаление офлайн-пакета не удаляет прогресс, XP или серверную историю ученика.

## Очередь синхронизации

Каждое событие получает уникальный `eventId` и сохраняется в `syncQueue` до подтверждения сервера.

Пример:

```json
{
  "eventId": "uuid",
  "type": "TEST_COMPLETED",
  "payload": {
    "testId": "demo-grade-8",
    "grade": 8,
    "scorePercent": 85
  },
  "createdAt": "..."
}
```

Клиент не отправляет `amount` XP как доверенное значение. Сервер самостоятельно определяет награду.

## Защита от повторной отправки

Cloudflare D1 хранит обработанные `sync_events`. Повторное событие с тем же `eventId` и тем же содержимым возвращается как `DUPLICATE` и не начисляет XP повторно. Попытка повторно использовать `eventId` с другим содержимым отклоняется как `event_id_conflict`.

## XP за тематический тест

Серверная шкала v1:

- меньше 50% — 0 XP;
- 50–69% — до 20 XP;
- 70–84% — до 35 XP;
- 85–99% — до 50 XP;
- 100% — до 60 XP.

При улучшении результата сервер начисляет только разницу до ранее достигнутой награды по этому тесту.

## Недельный рейтинг

Время начисления XP задаёт сервер при синхронизации. Локальные часы устройства не определяют рейтинговую неделю.

## PWA

`public/sw.js` кэширует оболочку приложения и уже запрошенные статические ресурсы. Учебный контент хранится отдельно в IndexedDB и скачивается только по действию ученика.

Background Sync пока не является обязательной зависимостью: синхронизация запускается при появлении сети, открытии приложения и вручную из вкладки «Офлайн-материалы».
