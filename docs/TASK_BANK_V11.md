# Genius v11 — банк из 100 задач

## Что изменено

- В банк включено **100 уникальных по условию задач** из PDF, предоставленных пользователем.
- Условия сохранены по исходным материалам; исправлены только переносы строк и PDF-дефисы.
- Ссылки, заголовки сайта, даты печати, номера страниц и водяные знаки в пользовательские карточки не переносятся.
- В каждой задаче используется **единое поле ввода ответа**.
- Подсказки удалены полностью.
- После первой попытки доступно решение: физическая идея → формулы/связи → ответ.
- Ответы внесены после независимой физической проверки, а не автоматического копирования.
- Для 8 задач с рисунками созданы собственные inline-SVG схемы без внешних изображений и водяных знаков.
- Inline-схемы входят в JSON задачи и работают офлайн.

- Тепловые явления: 42

## Важное решение по структуре

Загруженный ранее учебник заканчивается на §40. Поэтому задачи по электромагнитным и световым явлениям не получили выдуманные номера §41–§60. Они находятся в отдельном разделе «Электромагнитные и световые явления». После загрузки продолжения учебника их можно точно привязать к параграфам.
