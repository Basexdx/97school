# Genius v9: 50 авторских задач

Этот выпуск реализует уточнённое задание пользователя: 50 задач без рисунков,
с разрешением создавать собственные условия и числовые данные.
Это авторские задания Genius, а не оригинальные задания открытого банка ФИПИ.

## Содержимое

- 50 задач по §1–§40 учебника Перышкина / Иванова, 8 класс.
- По одной задаче на каждый параграф и 10 дополнительных расчётных задач.
- 29 заданий с выбором одного ответа и 21 задание с числовым ответом.
- 47 базовых задач по 10 XP и 3 повышенных по 20 XP.
- Два раздела, фильтры параграфа, темы, сложности, типа и прогресса.
- Две подсказки и самостоятельное решение каждой задачи.
- Все задачи VERIFIED. ANSWER_MISMATCH и REVIEW_REQUIRED пусты.
  FIPI_ANSWER = null: опубликованных ключей ФИПИ для авторских задач не существует.
- Каждому числовому ответу соответствуют прямое вычисление и отдельная обратная проверка
  с рациональной арифметикой. Качественные ответы проверены разбором альтернатив.

## Запуск

Требуется Node.js 20.9+ (проверено на Node 24) и npm. Для Python-проверок — Python 3.

```sh
npm ci
npm run bank:build
npm run dev:web
```

Откройте `http://127.0.0.1:3000/tasks` — новый раздел доступен напрямую,
без демонстрационного сценария выдачи кода. Также он встроен в пункт «Задачи»
существующего интерфейса. Без серверной сессии работает локальная практика без XP.

Для полного локального запуска API:

```sh
npm run setup:local
npm run dev
```

Скрипт setup создаёт локальные секреты и применяет обе схемы D1.
Если исходная база уже подготовлена, достаточно `npm run db:tasks`.
Для действующей удалённой D1 нужно отдельно применить `cloudflare/task-bank.sql`
с настройками своего Cloudflare-проекта. Ни публикация, ни изменение удалённой базы
в рамках этого выпуска не выполнялись.

## Файлы и импорт

`bank/tasks.json` — полный банк с ответами, решениями, подсказками, происхождением
и результатами проверки. `bank/coverage.json` — статистика всех 40 параграфов.
`bank/answer-mismatch.json` и `bank/review-required.json` — отдельные списки.

`npm run bank:build` проверяет обязательные поля, диапазон курса, уникальность ID,
статус, XP и источники тематического соответствия. Он создаёт публичный каталог
и отдельный JSON каждой задачи в `public/task-bank/`. В ученические JSON не попадают
внутренние ссылки SOURCE и протокол CHECK. REVIEW_REQUIRED не публикуются.
Сервер импортирует тот же исходный JSON и проверяет присланный ответ самостоятельно.

Этот выпуск содержит только single_choice и numeric. Список допустимых категорий
в общей структуре шире, но формы ввода рисунков, соответствий и развёрнутых ответов
не являются частью этого выпуска. Не импортируйте такие задачи в ученический UI
без соответствующего расширения интерфейса.

При изменении банка обновляйте версию синхронно в скрипте сборки и Worker.
Попытки со старой версией сохраняются локально как отклонённые; автоматически
пересчитывать их по изменённому условию нельзя.

## Ответы, XP и повторение

Числовой ввод допускает десятичную запятую, точку, знак минус и научную запись.
Единица указана около поля и не вводится вместе с числом. Пустое значение, NaN,
Infinity, шестнадцатеричные числа и текст с единицами не принимаются за число.
Допуск у текущих задач нулевой: ответы получаются точными конечными числами.

Одна задача может принести XP ученику только один раз. Неверная попытка даёт 0 XP.
Повторное правильное решение не повышает уже начисленную награду.
Клиент не определяет XP: он показывает локальный разбор, а подтверждённый общий XP
принимает от сервера. После ошибки задача попадает в фильтр повторения;
последующий правильный ответ убирает её оттуда.

`POST /api/student/task-attempts` принимает studentId и массив попыток:
attemptId, eventId, taskId, version, answer. Требуется активная cookie-сессия ученика
8 класса. Проверяются принадлежность ученику, версия, статус задачи и ответ.
`GET` того же адреса возвращает подтверждённые попытки и общий XP.

Уникальные ключи (student_id, attempt_id), (student_id, event_id) и
(student_id, task_id) предотвращают повторное начисление. Вставка попытки,
награда, запись XP и обновление class_progress выполняются одной SQLite-транзакцией
с триггерами. Конфликт идентификатора с другим ответом отклоняется.

Старые демонстрационные тесты передавали клиентский процент. Начисление XP по
такому проценту отключено до внедрения серверных ключей этих тестов.
Ежедневный вход также не начисляет XP. Ранее накопленные данные не удаляются.
Старые экраны рейтинга и кабинета учителя остаются прототипными; этот выпуск
обновляет серверные class_progress/xp_events, но не заменяет весь рейтинг приложения.

## Офлайн

Каталог не загружает автоматически тексты всех задач. Для сохранения доступны
«Скачать задачи темы» (параграф) и «Скачать раздел» с оценкой объёма JSON.
Данные попадают в IndexedDB; service worker не кэширует задачи при простом просмотре.
Скачанные пакеты видны в «Офлайн-материалах», откуда их можно удалить.

Попытки хранятся отдельно от контента и привязаны к ID ученика. До подтверждения
статус PENDING_SYNC. Попытки гостя имеют LOCAL_PRACTICE и не отправляются
автоматически в аккаунт другого человека. Перед отправкой заново проверяется
текущая серверная сессия. Удаление контента не удаляет попытки и серверный прогресс.
Для офлайн-запуска сначала откройте приложение онлайн и дайте service worker
активироваться; затем скачайте нужные задачи.

## Проверки и ограничения

Проверены сборка Next.js, сборка Worker, все ключи ответов, строгий числовой ввод,
прямая и обратная арифметика, повторная отправка, разные ученики, откат транзакции
при сбое, авторизация Worker, офлайн-загрузка, изоляция гостя, синхронизация и
сохранность попыток после удаления контента.

```sh
npm run test:bank
npm run build
npx wrangler deploy --dry-run
```

Интеграционные проверки используют настоящий SQLite и эмуляцию IndexedDB.
Это не испытание на физических смартфонах или удалённой Cloudflare D1.
Визуальная проверка в браузере в этой среде не завершилась: соединение с локальным
приложением не установилось. Проверка сборки не заменяет такого просмотра.
