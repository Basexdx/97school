# Genius v10 — банк задач

v10 развивает механику банка задач v9 и не меняет происхождение его 50 задач: текущий набор является авторским контентом Genius.

## Интерфейс ученика

Банк встроен в основную навигацию `Задачи` и доступен напрямую по `/tasks`.

Добавлены:

- четыре показателя прогресса: решено, точность, задачи на повторение и ожидающие синхронизации;
- поиск по теме/параграфу;
- быстрая полоса §1–§40;
- фильтры по разделу, параграфу, теме, сложности, типу и прогрессу;
- визуальные состояния карточек: новая, решена, повторить, ожидает синхронизации;
- педагогическая блокировка полного разбора до первой попытки;
- двухступенчатые подсказки;
- отдельный статус серверного подтверждения XP.

## Offline-first

Задачи не скачиваются все автоматически. Пользователь явно выбирает:

- `Скачать тему`;
- `Скачать раздел`.

Контент хранится в IndexedDB. Попытки хранятся отдельно от скачанного контента. Удаление офлайн-пакета не удаляет историю попыток.

## Серверная проверка

Клиент отправляет только идентификаторы и ответ. Worker повторно проверяет ответ по серверной копии банка. XP определяется сервером, а уникальные `attempt_id`/`event_id` предотвращают повторное начисление.

Версия контента централизована в `shared/task-bank-meta.mjs` и используется сборщиком банка, Worker и клиентским экраном офлайн-материалов.

## Проверки

Без внешних зависимостей можно выполнить:

```sh
node --test tests/task-checker.test.mjs
python3 tests/task-bank-sql.py
```

Полный набор после `npm ci`:

```sh
npm run test:bank
npm run build
```
