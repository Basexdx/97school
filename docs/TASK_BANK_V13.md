# Genius v13 — пакет задач Перышкина

В общий банк добавлены задачи из предоставленного пользователем сборника А. В. Перышкина «Сборник задач по физике. 7–9 классы»:

- 736–819;
- 836–865;
- 876–900;
- 918–947.

Это **169 новых задач**. Вместе с предыдущими 150 задачами банк содержит **319 задач**.

## Особенности v13

- условия перенесены вручную и сверены с предоставленным PDF;
- задачи со звёздочкой в сборнике помечены как **повышенный уровень**;
- для задач 839 и 852 графики построены заново в SVG-компоненте Genius с сохранением числовых отметок;
- для задачи 862 рисунок ледяного калориметра перерисован в стилистике Genius;
- подробные решения для нового пакета пока не публикуются;
- ответы для нового пакета сохраняются как черновые и пока не проверяются автоматически;
- переключение между задачами работает стрелками сверху и снизу карточки;
- добавлен запуск Genius в один клик на Windows через `Genius_Start.vbs`;
- `Create_Genius_Desktop_Shortcut.vbs` создаёт ярлык Genius на рабочем столе.
