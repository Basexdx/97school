# Genius — Design System v7

## Зафиксированный стиль

- фон: глубокий тёмно-синий / космический;
- акцент: яркий электрический синий;
- логотип: атом с ядром и орбитами;
- карточки: тёмные, слегка прозрачные, с тонкой синей рамкой;
- прогресс: светящиеся синие полосы;
- позитивные состояния: зелёный;
- XP и награды: золотой;
- интерфейс должен одинаково узнаваемо выглядеть на Windows, Android и iOS PWA.

## Урок

Типовой урок строится так:

1. Обзор и цели.
2. Короткие смысловые карточки.
3. Интерактивная модель / визуализация.
4. Проверка понимания по ходу урока.
5. Блок «Запомни».
6. Итоговый тест.
7. XP только за результат теста.
8. Кнопка сохранения урока офлайн.

## Mobile

На узком экране применяется нижняя навигация, крупные сенсорные кнопки и одноколоночные карточки. Тяжёлые данные не скачиваются автоматически — ученик сам выбирает офлайн-пакеты.
