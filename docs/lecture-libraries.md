# Библиотеки лекций

Раздел «Учебник» показывает тематический курс для 7, 8 и 9 классов. Каждая библиотека — отдельный JSON-файл. Встроенные файлы указаны в `public/lecture-libraries/index.json`; их можно обновлять отдельно от программного кода. Существующие интерактивные уроки остаются во вкладке «Уроки и темы».

Ученик может выбрать «Подключить библиотеку» и открыть файл JSON с устройства. Файл проверяется и сохраняется в IndexedDB именно на этом устройстве. Ответы, XP и статистика хранятся отдельно и не удаляются при подключении лекций. Для распространения собственной библиотеки можно отправить ученикам один JSON-файл.

Формат версии 1:

```json
{
  "schemaVersion": 1,
  "id": "my-physics-7",
  "title": "Дополнительные лекции · 7 класс",
  "grade": 7,
  "description": "Краткое описание библиотеки",
  "source": "Источник и редакция",
  "lessons": [{
    "id": "my-lecture-01",
    "title": "Название темы",
    "section": "Механика",
    "summary": "Короткое описание карточки",
    "intro": "Развёрнутое введение",
    "blocks": [{
      "heading": "Понятие",
      "text": "Объяснение физического смысла",
      "equations": ["v=\\frac{s}{t}"],
      "symbols": "v — скорость; s — путь; t — время.",
      "conditions": "Формула применима для равномерного движения.",
      "source": "§ 16"
    }],
    "takeaway": "Что ученик должен понять после чтения"
  }]
}
```

Текст отображается как текст; HTML и скрипты из файла не исполняются. Формулы пишутся в формате KaTeX. Идентификаторы библиотек должны быть уникальными и состоять из латинских букв, цифр, дефиса и подчёркивания. Файлы до 2 МБ; до 120 лекций по 12 блоков на тему. Для замены своей библиотеки подключите обновлённый файл с тем же `id`.

Встроенный курс собран из тематических блоков формул подготовленного Word-файла по учебникам Перышкина для 7–9 классов. Он не содержит рисунков и длинных машинных расшифровок страниц. Источник для воспроизводимой сборки — `content/lecture-formulas.json`; выполнить `python3 scripts/build-lecture-libraries.py`.
