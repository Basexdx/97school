# Genius — автономная версия 1.7.0

Установщики Windows и Android включают учебные материалы и банк задач. Развёртывание сервера и коды доступа не требуются.

При первом запуске укажите имя или никнейм и класс. Доступны материалы 7–9 классов, задачник, банк ФИПИ, формулы и справочные таблицы. Встроенные ключи проверяют расчётные ответы. Ответы на качественные задачи сохраняются без автоматической оценки.

Попытки и XP хранятся на этом устройстве. За повторное правильное решение уже решённой задачи XP повторно не начисляется. Перед удалением приложения сохраните резервную копию в разделе «Мой профиль». Копию можно восстановить на другом устройстве через тот же раздел; восстановление заменяет его локальные попытки и настройки.

В автономной версии нет подключения к классу, общего журнала или автоматической синхронизации между устройствами. Для самостоятельного обучения интернет не нужен.

## Сборка

- `npm ci`
- `npm run build:standalone`
- Windows: `npm install --no-save electron electron-builder`, затем `npx electron-builder --config desktop/electron-builder.yml --win --publish never` на Windows.
- Android: установить `@capacitor/cli@7 @capacitor/android@7`, выполнить `npx cap add android`, `npx cap sync android`, затем `android/gradlew assembleDebug` с JDK 21 и Android SDK.

Автоматическая сборка установщиков: `.github/workflows/package-apps.yml`. Веб-версия с сервером сохраняет прежний режим без переменной `NEXT_PUBLIC_GENIUS_STANDALONE=1`.

Windows использует постоянный локальный адрес внутри приложения для сохранения IndexedDB между перезапусками. Внешние сетевые подключения для автономного режима не требуются. Android использует встроенное хранилище WebView. Резервная копия на Android передаётся через системное меню «Поделиться».
