# Genius — автономная версия 1.8.0

## Вход без пароля в Windows-обновлении 1.8.2

Архив `Genius-Windows-Update-1.8.4.zip` заменяет только `resources/app.asar`. В нём выровнены шапки разделов и поле поиска ФИПИ, формульные обозначения набраны курсивом при прямом тексте пояснений, на карточках ФИПИ показаны полоски сложности, а после правильного ответа видно фактически начисленное XP за задачу. При первом входе после обновления ученик указывает имя, фамилию, класс, выбирает аватар и задаёт логин и новый пароль. Для профилей версии 1.8.2 прежний пароль не нужен: данные профиля обновляются на устройстве, а ответы, XP, просмотры и рейтинг сохраняются. При перезапуске приложения стартовый экран остаётся; обновление страницы внутри сессии сохраняет текущий раздел. Сейчас доступны отдельные библиотеки задачника, ФИПИ, справочных материалов и формул; «Учебник» и «Лабораторные работы» показывают сообщение о незагруженной библиотеке. Материалы лекций предыдущей версии сохранены в исходниках для будущего подключения.

Пять основных цветов интерфейса RGB: космический фон (3, 18, 33), панель (7, 29, 49), синий акцент (38, 165, 242), золотой акцент (245, 195, 99), светлый текст (238, 247, 255).

Архив `Genius-Windows-Update-1.8.2.zip` заменяет только `resources/app.asar`. Существующий профиль открывается кнопкой «Войти», вводить пароль больше не нужно. При создании профиля ученик выбирает никнейм, класс и аватар без создания пароля. При перезапуске приложения стартовый экран остаётся, а обновление страницы внутри открытой сессии сохраняет текущий раздел. Прежний хэш пароля и все локальные данные (ответы, XP, просмотры и подключённые библиотеки) остаются на устройстве.

Пока пароль не запрашивается, любой человек с доступом к этому сеансу Windows сможет открыть профиль Genius. APK 1.8.0 не меняется от установки Windows-архива.

## Обновление лекций 1.8.1 для Windows

Архив `Genius-Windows-Update-1.8.1.zip` обновляет установленную версию 1.8.0: закройте Genius и замените `resources/app.asar` файлом из архива. В «Учебнике» появится курс из 41 лекции для 7–9 классов, разбитый на отдельные библиотеки. Ответы, XP, профиль и подключённые с устройства библиотеки остаются в локальном хранилище. Лекции включены в пакет и работают без сети. Формат дополнительных библиотек описан в `docs/lecture-libraries.md`.

Для Android этот Windows-архив не подходит. На телефон нужен APK с увеличенным `versionCode`, подписанный тем же постоянным ключом, что и версия 1.8.0.

При первом запуске ученик выбирает никнейм, один из 12 аватаров и класс 7–9, затем задаёт пароль. Вход выполняется на прежнем стартовом экране с комнатой, книгами и сезонной анимацией. Пароль проверяется локально; вместо него хранится соль и PBKDF2-хэш. После перезапуска приложения нужен повторный вход, при обновлении страницы открытая сессия сохраняется.

Учебник поддерживает поиск по названию и содержимому темы и фильтр по разделам. В ученическом задачнике остаются краткие числовые ответы, выбор вариантов и соответствия. Задачи со свободным текстовым ответом исключены из автономной публикации; их исходники и проверенные эталоны сохранены в исходном банке.

Профиль содержит статистику просмотров, решённых и оставшихся задач по разделам и темам. Задача с сохранённой попыткой считается просмотренной. Тема завершена, если решены все относящиеся к ней задачи. Просмотренные задачи включают решённые, поэтому эти два числа не надо складывать. XP сохраняется полностью, включая старые попытки по заданиям, которых больше нет в текущем списке. За повторное правильное решение XP не начисляется.

## Обновление Windows без переустановки

Закройте Genius. Распакуйте архив `Genius-Windows-Update-1.8.0.zip` и скопируйте папку `resources` в папку с установленным `Genius.exe`, подтвердив замену `resources/app.asar`. Запустите приложение. В существующем профиле один раз выберите аватар и задайте пароль. Ответы, никнейм, просмотры и XP остаются на месте; резервная копия для обновления не требуется.

Пакет обновления сохраняет имя приложения `genius-prototype-v16-multigrade`, тот же профиль Electron, IndexedDB и постоянный внутренний адрес `127.0.0.1:28697`. Данные пользователя находятся вне `resources/app.asar`. Удалять приложение или папку данных нельзя. Такой пакет подходит для изменений интерфейса и учебных материалов; обновление самого Electron при необходимости распространяется установщиком поверх существующего приложения.

## Переход Android 1.7 → 1.8

Первый APK 1.7 был подписан временным ключом от сборочной среды, который не сохранялся. Обычное обновление поверх него невозможно. Чтобы сохранить результаты, в старой версии 1.7 сначала выгрузите прогресс через её профиль. После установки 1.8 выберите на стартовом экране «Перенести прогресс из версии 1.7», укажите полученный JSON, затем выберите аватар и создайте пароль. Это однократный переход. В профиле 1.8 функций резервного копирования нет.

Распространяемый APK 1.8 подписывается отдельным постоянным ключом владельца. Последующие APK с тем же ключом и увеличенным versionCode устанавливаются поверх 1.8, сохраняя данные. Не распространяйте сборочный debug APK: для выдачи ученикам его необходимо переподписать постоянным ключом. Ключ и пароль нельзя включать в публичный Git-репозиторий.

## Сборка

- `npm ci`
- `npm run build:standalone`
- Windows: `npm install --no-save electron electron-builder @electron/asar@3.4.1`, затем `npx electron-builder --config desktop/electron-builder.yml --win --publish never` и `node scripts/package-windows-update.mjs`.
- Android: установить `@capacitor/cli@7 @capacitor/android@7`, выполнить `npx cap add android`, `npx cap sync android`, `node scripts/prepare-android-standalone.mjs`, затем `android/gradlew assembleDebug` с JDK 21 и Android SDK. Финальный APK переподписать постоянным ключом.

Общего журнала и сетевой синхронизации между автономными устройствами нет. Все учебные материалы и шрифт включены в приложение, интернет для обучения не требуется.
